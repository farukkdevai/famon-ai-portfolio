## Türkçe

### Proje Hakkında

**Famon AI Assistant**, günlük dijital iş yükünü azaltmak amacıyla geliştirilen yerel öncelikli bir kişisel yapay zekâ asistanı projesidir.

Projenin amacı yalnızca sorulara yanıt veren bir sohbet botu oluşturmak değil; araştırma, planlama, metin çalışmaları ve yapılandırılmış görevleri tek bir kullanıcı deneyiminde birleştiren güvenilir bir asistan geliştirmektir.

### Temel Hedefler

- Doğal ve bağlama duyarlı konuşmalar oluşturmak
- Kullanıcının aktif görevini ve önceki kararlarını korumak
- Planlama, yazma ve içerik çalışmalarını yapılandırılmış araçlarla desteklemek
- Yerel yapay zekâ modelleriyle gizlilik odaklı kullanım sağlamak
- Gerçek kullanıcı geri bildirimleriyle ürünü adım adım geliştirmek

### Öne Çıkan Yetenekler

- Doğal sohbet ve bağlam takibi
- Mesaj yazma ve metin düzeltme
- Plan oluşturma ve plan revizyonu
- Özetleme ve açıklama
- Fikir üretme ve karşılaştırma
- Hesaplama aracı
- Akış hâlinde yanıt üretimi
- Görev durumu ve sürüm mantığıyla daha güvenilir revizyonlar

### Projedeki Rolüm

Projede **kurucu, ürün geliştirici ve kalite süreci yöneticisi** olarak:

- Ürün vizyonunu ve kullanıcı senaryolarını belirliyorum.
- Görev akışlarını ve akıllı araçların davranışlarını tasarlıyorum.
- Yapay zekâ yanıtlarını tutarlılık, hız, doğruluk ve kullanıcı deneyimi açısından test ediyorum.
- Gerçek kullanıcı geri bildirimlerini geliştirme önceliklerine dönüştürüyorum.
- AI destekli geliştirme araçlarıyla teknik görevleri planlıyor; değişiklikleri ve test sonuçlarını inceliyorum.
- Dar ve ezbere dayalı çözümler yerine genellenebilir ürün ve mimari mantığına odaklanıyorum.

### Teknoloji Özeti

- Python
- FastAPI
- Ollama ve yerel dil modelleri
- HTML, CSS ve JavaScript tabanlı web arayüzü
- Git ve GitHub
- AI destekli geliştirme ve kalite kontrol süreçleri

### Mevcut Durum

Famon aktif geliştirme aşamasındaki çalışan bir prototip/beta üründür. Temel sohbet, akıllı araçlar, görev devamlılığı, plan revizyonları ve akış hâlinde yanıt deneyimi üzerinde çalışılmaktadır.

Proje sınırlı bir aile pilotunda gerçek kullanıcılarla test edilmiş; hız, konuşma devamlılığı, yapılandırılmış çıktı ve kullanıcı deneyimi sorunları kayıt altına alınarak geliştirme planına dönüştürülmüştür.

### Vizyon

Uzun vadeli hedef; araştırma, içerik üretimi, planlama ve diğer dijital iş yüklerini güvenilir biçimde üstlenebilen, farklı araçları tek deneyimde birleştiren kişisel bir yapay zekâ asistanı oluşturmaktır.

## English

### Project Overview

**Famon AI Assistant** is a local-first personal AI assistant project designed to reduce everyday digital workload.

The goal is not to build another chatbot that only answers questions. Famon is being developed as a reliable assistant that combines research, planning, writing support, and structured tasks in one consistent user experience.

### Core Goals

- Create natural and context-aware conversations
- Preserve the user’s active task and previous decisions
- Support planning, writing, and content workflows with structured tools
- Provide a privacy-oriented experience through local AI models
- Improve the product step by step through real user feedback

### Key Capabilities

- Natural conversation and context handling
- Message writing and text correction
- Plan creation and plan revision
- Summarization and explanation
- Ideation and comparison
- Calculator tool
- Streaming responses
- More reliable revisions through task-state and versioning logic

### My Role

As the **founder, product developer, and quality process owner**, I:

- Define the product vision and user scenarios
- Design task flows and smart-tool behavior
- Test AI responses for consistency, speed, accuracy, and user experience
- Turn real user feedback into development priorities
- Coordinate technical tasks with AI-assisted development tools and review changes and test results
- Prefer generalizable product and architecture improvements over narrow hardcoded fixes

### Technology Overview

- Python
- FastAPI
- Ollama and local language models
- HTML, CSS, and JavaScript web interface
- Git and GitHub
- AI-assisted development and quality review workflows

### Current Status

Famon is an actively developed working prototype/beta focused on core conversation, smart tools, task continuity, plan revision, and streaming response experience.

The project has been tested in a limited family pilot. Feedback about speed, conversation continuity, structured output, and usability has been documented and converted into product priorities.

### Vision

The long-term vision is to build a personal AI assistant that can reliably support research, content creation, planning, and other forms of digital workload while bringing multiple tools together in one unified experience.

### Privacy

The main Famon source code is maintained in a private GitHub repository. This repository is provided only as a public project overview and portfolio.
